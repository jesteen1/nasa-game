ROCKET SIMULATOR - NASA DATA SOURCES
====================================
Project : Rocket Simulator (nasa-game)
Compiled: 2026-11-15
Purpose : NASA-derived data used in the app, with source links, for the
          NASA Space Apps Challenge global judging submission.

NOTE
----
NASA reference values are adapted/rounded for a deterministic arcade
simulation. They are not flight-certified. NASA does not endorse this project.

1. ATMOSPHERE AND EARTH MODEL
------------------------------
File: src/game/sim/atmosphere.ts
Used for: density, pressure and temperature from 0 to 100 km; gravity;
          speed of sound; dynamic pressure.
Source : U.S. Standard Atmosphere, 1976 (NASA TM-X-74335)
Link   : https://ntrs.nasa.gov/citations/19770009539

Source : NASA NSSDC Earth Fact Sheet (mean radius 6371 km, g0 9.80665 m/s2)
Link   : https://nssdc.gsfc.nasa.gov/planetary/factsheet/earthfact.html

2. NASA ENGINES
----------------
File: src/game/data/parts.ts

RS-25 (part id: eng_rs25)
  In app: 1,860 kN sea level / 2,279 kN vacuum; Isp 366 / 452 s
  Source: NASA SLS RS-25 Core Stage Engine
  Link  : https://www.nasa.gov/reference/space-launch-system-rs-25-core-stage-engine/

F-1 (part id: eng_f1)
  In app: 6,770 kN sea level / 7,770 kN vacuum; Isp 263 / 304 s
  Source: NASA Marshall - The Mighty F-1 Engine
  Link  : https://www.nasa.gov/centers/marshall/history/f1_engine_new.html

J-2 (part id: eng_j2)
  In app: 1,090 kN vacuum; Isp 421 s
  Source: NASA - Saturn launch vehicle history (PDF)
  Link  : https://www.nasa.gov/wp-content/uploads/static/history/alsj/02_Saturn_Launch_Vehicles_pp8-14.pdf

ICPS / RL10 (part id: eng_icps)
  In app: 110 kN vacuum; Isp 465 s
  Source: NASA SLS Interim Cryogenic Propulsion Stage (ICPS)
  Link  : https://www.nasa.gov/reference/icps/

5. MISSION CONTEXT AND SETTING

6. NOT NASA DATA (TRANSPARENCY)
--------------------------------
- Falcon-X / Merlin and Starship / Raptor tiers: SpaceX-derived, commercial.
- All failure rules, tolerances, ascent reference curves and scoring:
  original simulation design.
- 120 km target and 100 km Karman line: game design target, not a NASA dataset.
- All artwork: procedurally generated in-repo; no NASA images embedded.
